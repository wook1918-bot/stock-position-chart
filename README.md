# 주가위치분석시스템 차트 (KRX)

국내 상장 종목·지수(코스피/코스닥)의 일봉/주봉 로그 차트에 **바닥~상투 위치 밴드**, 이동평균선(40/50/60/120), Slow Stochastics(12,5,5), 거래량을 함께 그려 주는 Streamlit 웹앱입니다.

## 기능

- 종목명/6자리 종목코드 조회 (네이버 증권 자동완성 API, 예: `삼성전자`, `세방전지`, `005930`)
- **지수 조회**: `코스피`(KOSPI), `코스닥`(KOSDAQ) — 지수는 가격을 `p` 단위로 표시
- 일봉 / 주봉 선택, 표시 봉수 120~500 조절, 로그 스케일 토글
- 단계별 가격표(바닥·발목·무릎·허벅지·허리·어깨·상투)와 현재가 괴리율(%)
- 무릎(파랑) 아래 종목 스캐너

## 지표 계산 (2026-11 개정)

댕기왕자(blog.naver.com/deekelly) 블로그 차트 34개 지점(12종목·지수)을 실제 KRX 일봉과 대조해 역산했습니다.

```
기준선(무릎) = 1.05 × (고가 120봉 평균)^0.30 × (고가 650봉 평균)^0.70
단계        = 기준선 × exp(z × s)
s           = clip(0.44 + 0.30 × (연변동성 - 0.5), 0.25, 0.75)
z           = 바닥 -1.62 / 발목 -1.10 / 무릎 0.00 / 허벅지 +0.82 / 허리 +1.66 / 어깨 +2.25 / 상투 +2.85
```

- 기존(종가 로그 EMA260 + z×변동성) 대비 평균 절대오차 **9.4% → 7.4%**, 중앙값 6.0% → 3.8%
- 코스피(2026-11-26 기준) 무릎 오차 **+12.5% → +2.0%**, 전 구간 최대 오차 5.1%
- 주봉은 봉 수를 1/5로 환산(24/130봉, 변동성 52봉)
