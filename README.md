# 주가위치분석시스템 차트 (KRX)

국내 상장 종목의 일봉/주봉 로그 차트에 **발목~상투 위치 밴드**, 이동평균선(40/50/60/120), Slow Stochastics(12,5,5), 거래량을 함께 그려 주는 Streamlit 웹앱입니다.

## 기능

- 종목명 또는 6자리 종목코드로 조회 (네이버 증권 자동완성 API 사용, 예: `삼성전자`, `세방전지`, `005930`)
- 일봉 / 주봉 선택, 표시 봉수 120~500 조절, 로그 스케일 토글
- 로그 기하이동평균(일봉 300, 주봉 100) ± 변동성 밴드로 계산한 단계별 가격표
  - 연보라(하) -1.28σ · 얇은빨강 -0.90σ · 연보라(상) -0.60σ · 무릎(파랑) 0.00σ
  - 허벅지(주황) +0.82σ · 허리(검정) +1.66σ · 어깨(초록) +2.40σ · 상투(빨강) +3.06σ
- 현재가 기준 각 구간의 가격과 현재가 대비 괴리율(%) 표

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud 배포

1. https://share.streamlit.io 에서 이 저장소를 선택
2. Main file path: `app.py`
3. Deploy
